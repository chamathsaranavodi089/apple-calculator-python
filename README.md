# Apple Calculator – Python Tkinter

An Apple-inspired calculator application developed using **Python and Tkinter**.
The interface is designed to resemble the iPhone Calculator with a dark theme, circular buttons, and an Apple-inspired layout.

## ✨ Features

* Apple-inspired calculator interface
* Dark-themed GUI
* Addition (+)
* Subtraction (-)
* Multiplication (×)
* Division (÷)
* Percentage (%)
* Positive/Negative (+/-)
* Decimal calculations
* Clear (AC) functionality
* Division-by-zero error handling
* Dynamic display sizing for longer numbers
* iPhone-style circular calculator buttons
* Wide zero button similar to the iPhone Calculator

## 🛠️ Technologies Used

* **Python**
* **Tkinter**
* **Object-Oriented Programming (OOP)**

## ▶️ How to Run

### 1. Install Python

Make sure Python is installed on your computer.

### 2. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/apple-calculator-python.git
```

### 3. Open the project folder

```bash
cd apple-calculator-python
```

### 4. Run the calculator

```bash
python apple_calculator.py
```
